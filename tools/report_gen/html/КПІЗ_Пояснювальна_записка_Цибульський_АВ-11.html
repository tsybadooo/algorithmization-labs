2 РОЗГАЛУЖЕННЯ ТА ЦИКЛИ

2.1 Постановка задачі

Скласти програму табулювання кусково заданої функції на відрізку [a0; b0] з кроком h; a0, b0, h і параметр a > 0 вводяться з клавіатури:

y(x) = |sin x|, x < −π;    y(x) = x + a, −π ≤ x ≤ π;    y(x) = 1/√(x − π), x > π.       (2.1)

Результат — таблиця з вирівняними стовпцями (номер, x, y, номер гілки), сума, середнє, максимум і мінімум значень. Табулювання реалізується трьома видами циклів з вибором через switch; одну з гілок обчислено тернарним оператором.

2.2 Опис програми

Програма складається з модуля func.h/func.c (функції branch_of, calc_y, eval_point, points_count) і головного модуля main.c (введення з перевіркою, меню, табулювання, статистика). Вибір між другою і третьою гілками виконано тернарним оператором у branch_of: return (x <= KPIZ_PI) ? 2 : 3;. Функція calc_y повертає ознаку визначеності через параметр-покажчик ok; для третьої гілки додатково перевіряється, що √(x − π) ≠ 0, щоб уникнути ділення на нуль при x, дуже близьких до π. Глобальних змінних немає: статистика накопичується у структурі Stats, яка передається за покажчиком.

2.3 Вибір типів даних і похибки перетворення

Для x, y, a, a0, b0, h обрано тип double (15–16 значущих цифр): тип float (6–7 цифр) дав би помітну похибку при накопиченні суми та поблизу x = π. Номер точки і кількість точок мають тип long, номер гілки — int.

Можливі похибки: 1) крок 0,1 не подається точно у двійковій системі, тому накопичення x += h дає дрейф (після 10 кроків x = 0,9999999999999999 замість 1,0) і втрату останньої точки; тому x обчислюється як a0 + i·h, а кількість точок — з допуском 10⁻⁹. 2) Перетворення double → long при обчисленні N виконується після floor(), щоб уникнути неявного відкидання дробової частини. 3) Порівняння x з межами ±π виконується без допуску, оскільки самі межі є значеннями double (константа KPIZ_PI), тож точки −π і π потрапляють у другу гілку, як вимагає (2.1). 4) У виразі sum / count лічильник явно приводиться до double.

Рисунок 3.3 – Залежність кількості порівнянь від розміру масиву (логарифмічні шкали)

Для бульбашки кількість порівнянь практично дорівнює n(n−1)/2 (O(n²)): рання зупинка спрацьовує лише на останніх проходах. Для швидкого сортування кількість порівнянь зростає як n log n і менша за теоретичну оцінку 1,39·n·log₂n, бо масиви містять багато однакових значень (лише 101 різне значення), а схема Хоара не переставляє рівні опорному елементи без потреби. При n = 10 000 співвідношення кількості порівнянь бульбашки і швидкого сортування становить ≈ 341 : 1.

Лінійний пошук має складність O(n) (у протоколі — 2 порівняння для елемента з індексом 1), бінарний — O(log n): для масиву з 50 елементів не більше 6 порівнянь (тест у CUnit).

4.2 Алгоритм пошуку анаграм

Слова є анаграмами тоді й лише тоді, коли збігаються їхні ключі — упорядковані за зростанням коди літер у нижньому регістрі (для «Кабан» і «БАНКА» ключ «аабкн»). Алгоритм:

  1. для кожного слова будується пара (слово в нижньому регістрі, ключ); однолітерні слова пропускаються;
  2. масив пар сортується qsort() за ключем, а за рівних ключів — за словом;
  3. однакові ключі опиняються поруч; послідовність пар з однаковим ключем, що містить щонайменше два різні слова, утворює групу; повтори того самого слова враховуються один раз.

Складність — O(W·log W) порівнянь рядків для W слів (замість O(W²) при попарному порівнянні). Текст вводиться в кодуванні UTF-8, у якому українська літера займає 2 байти, тому стандартні функції ctype.h (isalpha, tolower) для кирилиці не придатні. Самостійно, без бібліотечних аналогів, написано функції utf8_decode, utf8_encode, utf8_strlen (кількість символів, а не байтів), cp_is_letter, cp_to_lower (враховує Ґ, Є, І, Ї), word_to_lower, make_anagram_key і is_anagram.

Під час розбиття на слова strtok використовує лише ASCII-роздільники: багатобайтові символи («, », —) не можна передавати в strtok, бо їхні байти збігаються з байтами літер. Такі символи відкидаються з країв слова окремим проходом. Речення рахуються за послідовностями «.», «!», «?»: «?!» і «...» вважаються одним кінцем речення.

/**
 * @file func.c
 * @brief Реалізація функції y(x) варіанта 19.
 */
#include <stddef.h>
#include <math.h>
#include "func.h"

int branch_of(double x)
{
    if (x < -KPIZ_PI) return 1;
    return (x <= KPIZ_PI) ? 2 : 3;   /* друга/третя гілка - тернарний оператор */
}

double calc_y(double x, double a, int *ok)
{
    int defined = 1;
    double y = 0.0;

    switch (branch_of(x)) {
        case 1:
            y = fabs(sin(x));
            break;
        case 2:
            y = x + a;
            break;
        default: {
            double d = x - KPIZ_PI;           /* для x > pi завжди d > 0 */
            /* Захист від переповнення: якщо d настільки мале, що sqrt(d)
               дорівнює 0 у double, значення вважаємо невизначеним. */
            if (d <= 0.0 || sqrt(d) == 0.0) defined = 0;
            else y = 1.0 / sqrt(d);
            break;
        }
    }
    if (ok != NULL) *ok = defined;
    return defined ? y : 0.0;
}

FuncResult eval_point(double x, double a)
{
    FuncResult r;
    r.branch = branch_of(x);
    r.y = calc_y(x, a, &r.ok);
    return r;
}

long points_count(double a0, double b0, double h)
{
    if (!(h > 0.0) || b0 < a0) return 0;
    double n = floor((b0 - a0) / h + 1e-9);   /* допуск на похибку округлення */
    if (n > 1e7) return 0;                    /* захист від надто малого кроку */
    return (long)n + 1;
}

/** Накопичувач статистики табулювання. */
typedef struct {
    double sum, min, max;
    long   count;      /* кількість точок, де y визначено */
    long   undefined;  /* кількість точок, де y не визначено */
} Stats;

/**
 * Читає дійсне число з повторним запитом у разі помилки.
 * @param prompt текст запиту
 * @param value [out] прочитане число
 * @return 1 - успішно, 0 - кінець вхідного потоку
 */
static int read_double(const char *prompt, double *value)
{
    for (;;) {
        printf("%s", prompt);
        int rc = scanf("%lf", value);
        if (rc == 1) { flush_line(); return 1; }
        if (rc == EOF) return 0;
        printf("  Помилка: введіть число.\n");
        flush_line();
    }
}

/** Обробляє одну точку: друк рядка таблиці та оновлення статистики. */
static void process_point(long i, double x, double a, Stats *st)
{
    FuncResult r = eval_point(x, a);
    if (r.ok) {
        printf("| %5ld | %12.5f | %14.6f |   %d   |\n", i + 1, x, r.y, r.branch);
        st->sum += r.y;
        if (st->count == 0 || r.y < st->min) st->min = r.y;
        if (st->count == 0 || r.y > st->max) st->max = r.y;
        st->count++;
    } else {
        printf("| %5ld | %12.5f | %14s |   %d   |\n", i + 1, x, "не визначено", r.branch);
        st->undefined++;
    }
}

int matrix_create(Matrix *mt, size_t rows, size_t cols)
{
    if (mt == NULL) return 0;
    mt->data = NULL;
    mt->rows = mt->cols = 0;
    if (rows == 0 || cols == 0) return 0;

    int **d = (int **)malloc(rows * sizeof(int *));
    if (d == NULL) return 0;
    for (size_t i = 0; i < rows; i++) {
        d[i] = (int *)calloc(cols, sizeof(int));
        if (d[i] == NULL) {                  /* відкат уже виділених рядків */
            for (size_t k = 0; k < i; k++) free(d[k]);
            free(d);
            return 0;
        }
    }
    mt->data = d;
    mt->rows = rows;
    mt->cols = cols;
    return 1;
}

void matrix_free(Matrix *mt)
{
    if (mt == NULL || mt->data == NULL) return;
    for (size_t i = 0; i < mt->rows; i++) free(mt->data[i]);
    free(mt->data);
    mt->data = NULL;
    mt->rows = mt->cols = 0;
}

void matrix_fill_random(Matrix *mt, int lo, int hi)
{
    for (size_t i = 0; i < mt->rows; i++)
        for (size_t j = 0; j < mt->cols; j++)
            mt->data[i][j] = lo + rand() % (hi - lo + 1);
}

{
    printf("       ");
    for (size_t j = 0; j < mt->cols; j++) printf("%5zu", j);
    printf("\n");
    for (size_t i = 0; i < mt->rows; i++) {
        printf("  %3zu |", i);
        for (size_t j = 0; j < mt->cols; j++) printf("%5d", mt->data[i][j]);
        printf("\n");
    }
}

int is_local_min(const Matrix *mt, size_t r, size_t c)
{
    int v = mt->data[r][c];
    /* Межі вікна 3x3 навколо елемента з урахуванням країв матриці.
       Використовуємо беззнакові індекси, тому r-1 обчислюємо лише при r > 0. */
    size_t r0 = (r > 0) ? r - 1 : 0;
    size_t r1 = (r + 1 < mt->rows) ? r + 1 : r;
    size_t c0 = (c > 0) ? c - 1 : 0;
    size_t c1 = (c + 1 < mt->cols) ? c + 1 : c;

    for (size_t i = r0; i <= r1; i++)
        for (size_t j = c0; j <= c1; j++) {
            if (i == r && j == c) continue;          /* сам елемент пропускаємо */
            if (mt->data[i][j] <= v) return 0;       /* знайдено не більшого сусіда */
        }
    return 1;
}

size_t count_local_minima(const Matrix *mt, Cell *cells, size_t max_cells)
{
    size_t count = 0;
    if (mt == NULL || mt->data == NULL) return 0;
    for (size_t i = 0; i < mt->rows; i++)
        for (size_t j = 0; j < mt->cols; j++)
            if (is_local_min(mt, i, j)) {
                if (cells != NULL && count < max_cells) {
                    cells[count].row = i;
                    cells[count].col = j;
                }
                count++;
            }
    return count;
}

{
    if (mt == NULL || mt->data == NULL || dst == NULL) return 0;
    for (size_t i = 0; i < mt->rows; i++) dst[i] = mt->data[i][mt->cols - 1];
    return 1;
}

{
    for (size_t i = 0; i < mt->rows; i++) mt->data[i][mt->cols - 1] = src[i];
}

#include "sort.h"

/** Обмін двох елементів з урахуванням лічильника. */
static void swap_int(int *a, int *b, SortStats *st)
{
    int t = *a;
    *a = *b;
    *b = t;
    if (st != NULL) st->swaps++;
}

/** Порівняння a > b з урахуванням лічильника. */
static int greater(int a, int b, SortStats *st)
{
    if (st != NULL) st->comparisons++;
    return a > b;
}

void bubble_sort(int *arr, size_t n, SortStats *st)
{
    if (arr == NULL || n < 2) return;
    for (size_t pass = 0; pass < n - 1; pass++) {
        int swapped = 0;
        for (size_t j = 0; j < n - 1 - pass; j++)
            if (greater(arr[j], arr[j + 1], st)) {
                swap_int(&arr[j], &arr[j + 1], st);
                swapped = 1;
            }
        if (!swapped) break;                    /* масив уже впорядкований */
    }
}

/** Рекурсивна частина швидкого сортування на відрізку [lo; hi]. */
static void quick_rec(int *arr, long lo, long hi, SortStats *st)
{
    if (lo >= hi) return;                       /* база рекурсії */
    int pivot = arr[lo + (hi - lo) / 2];
    long i = lo, j = hi;
    while (i <= j) {
        while (greater(pivot, arr[i], st)) i++;  /* arr[i] < pivot */
        while (greater(arr[j], pivot, st)) j--;  /* arr[j] > pivot */
        if (i <= j) {
            if (i != j) swap_int(&arr[i], &arr[j], st);
            i++;
            j--;
        }
    }
    quick_rec(arr, lo, j, st);                  /* ліва частина  */
    quick_rec(arr, i, hi, st);                  /* права частина */
}

void quick_sort(int *arr, size_t n, SortStats *st)
{
    if (arr == NULL || n < 2) return;
    quick_rec(arr, 0, (long)n - 1, st);
}

int is_sorted(const int *arr, size_t n)
{
    for (size_t i = 1; i < n; i++)
        if (arr[i - 1] > arr[i]) return 0;
    return 1;
}

    while (lo <= hi) {

        if (arr[mid] < key) lo = mid + 1;
        else hi = mid - 1;
    }
    if (comparisons != NULL) *comparisons = c;
    return found;
}

void strlist_init(StrList *l)
{
    l->items = NULL;
    l->count = 0;
    l->cap = 0;
}

int strlist_add(StrList *l, const char *s)
{
    if (l->count == l->cap) {
        size_t ncap = l->cap ? l->cap * 2 : 8;
        char **p = (char **)realloc(l->items, ncap * sizeof(char *));
        if (p == NULL) return 0;          /* старий блок лишається дійсним */
        l->items = p;
        l->cap = ncap;
    }
    size_t len = strlen(s);
    char *copy = (char *)malloc(len + 1);
    if (copy == NULL) return 0;
    memcpy(copy, s, len + 1);
    l->items[l->count++] = copy;
    return 1;
}

void strlist_free(StrList *l)
{
    for (size_t i = 0; i < l->count; i++) free(l->items[i]);
    free(l->items);
    strlist_init(l);
}

int utf8_decode(const char *s, uint32_t *cp)
{
    const unsigned char *u = (const unsigned char *)s;
    if (u[0] < 0x80) { *cp = u[0]; return 1; }
    if ((u[0] & 0xE0) == 0xC0 && (u[1] & 0xC0) == 0x80) {
        *cp = ((uint32_t)(u[0] & 0x1F) << 6) | (u[1] & 0x3F);
        return 2;
    }
    if ((u[0] & 0xF0) == 0xE0 && (u[1] & 0xC0) == 0x80 && (u[2] & 0xC0) == 0x80) {
        *cp = ((uint32_t)(u[0] & 0x0F) << 12) | ((uint32_t)(u[1] & 0x3F) << 6) | (u[2] & 0x3F);
        return 3;
    }
    if ((u[0] & 0xF8) == 0xF0 && (u[1] & 0xC0) == 0x80 && (u[2] & 0xC0) == 0x80 && (u[3] & 0xC0) == 0x80) {
        *cp = ((uint32_t)(u[0] & 0x07) << 18) | ((uint32_t)(u[1] & 0x3F) << 12) |
              ((uint32_t)(u[2] & 0x3F) << 6) | (u[3] & 0x3F);
        return 4;
    }
    *cp = 0xFFFD;                         /* некоректна послідовність */
    return 1;
}

int utf8_encode(uint32_t cp, char *out)
{
    if (cp < 0x80) { out[0] = (char)cp; return 1; }
    if (cp < 0x800) {
        out[0] = (char)(0xC0 | (cp >> 6));
        out[1] = (char)(0x80 | (cp & 0x3F));
        return 2;
    }
    if (cp < 0x10000) {
        out[0] = (char)(0xE0 | (cp >> 12));
        out[1] = (char)(0x80 | ((cp >> 6) & 0x3F));
        out[2] = (char)(0x80 | (cp & 0x3F));
        return 3;
    }
    out[0] = (char)(0xF0 | (cp >> 18));
    out[1] = (char)(0x80 | ((cp >> 12) & 0x3F));
    out[2] = (char)(0x80 | ((cp >> 6) & 0x3F));
    out[3] = (char)(0x80 | (cp & 0x3F));
    return 4;
}

size_t utf8_strlen(const char *s)
{
    size_t n = 0;
    while (*s != '\0') {
        uint32_t cp;
        s += utf8_decode(s, &cp);
        n++;
    }
    return n;
}

int cp_is_letter(uint32_t cp)
{
    if ((cp >= 'A' && cp <= 'Z') || (cp >= 'a' && cp <= 'z')) return 1;
    if (cp >= 0x0400 && cp <= 0x045F) return 1;          /* основна кирилиця */
    if (cp == 0x0490 || cp == 0x0491) return 1;          /* Ґ ґ */
    return 0;
}

uint32_t cp_to_lower(uint32_t cp)
{
    if (cp >= 'A' && cp <= 'Z') return cp + 32;
    if (cp >= 0x0410 && cp <= 0x042F) return cp + 0x20;  /* А..Я -> а..я */
    if (cp >= 0x0400 && cp <= 0x040F) return cp + 0x50;  /* Ѐ..Џ (Є, І, Ї) */
    if (cp == 0x0490) return 0x0491;                     /* Ґ -> ґ */
    return cp;
}

void word_to_lower(const char *word, char *out)
{
    while (*word != '\0') {
        uint32_t cp;
        word += utf8_decode(word, &cp);
        out += utf8_encode(cp_to_lower(cp), out);
    }
    *out = '\0';
}

size_t make_anagram_key(const char *word, char *out)
{
    uint32_t cps[MAX_LINE + 1];
    size_t n = 0;
    while (*word != '\0' && n < MAX_LINE) {
        uint32_t cp;
        word += utf8_decode(word, &cp);
        if (cp_is_letter(cp)) cps[n++] = cp_to_lower(cp);
    }
    /* сортування вставками кодових точок (слова короткі - O(k^2) достатньо) */
    for (size_t i = 1; i < n; i++) {
        uint32_t key = cps[i];
        size_t j = i;
        while (j > 0 && cps[j - 1] > key) { cps[j] = cps[j - 1]; j--; }
        cps[j] = key;
    }
    for (size_t i = 0; i < n; i++) out += utf8_encode(cps[i], out);
    *out = '\0';
    return n;
}

/** Розмір буферів для одного слова: MAX_LINE символів по 4 байти + '\0'. */
#define WORD_BUF (MAX_LINE * 4 + 1)

int is_anagram(const char *w1, const char *w2)
{

       word_to_lower/make_anagram_key ніколи не виходили за межі буферів;
       слова довші за MAX_LINE символів не можуть бути словами тексту. */
    if (strlen(w1) >= WORD_BUF || strlen(w2) >= WORD_BUF) return 0;
    char key[2][WORD_BUF], low[2][WORD_BUF];
    const char *w[2] = {w1, w2};
    for (int i = 0; i < 2; i++) {
        if (make_anagram_key(w[i], key[i]) == 0) return 0;   /* слово без літер */
        word_to_lower(w[i], low[i]);
    }
    return strcmp(key[0], key[1]) == 0 && strcmp(low[0], low[1]) != 0;
}

/** Чи починається з позиції s літера або цифра (для обрізання країв слова). */
static int starts_with_alnum(const char *s)
{
    uint32_t cp;
    utf8_decode(s, &cp);
    return cp_is_letter(cp) || (cp < 0x80 && isdigit((int)cp));
}

size_t split_words(const char *line, StrList *words)
{
    static const char DELIMS[] = " \t\r\n.,;:!?()[]{}\"/\\<>=+*&^%$#@~|";
    char buf[MAX_LINE * 4 + 2];
    size_t added = 0;

    strncpy(buf, line, sizeof buf - 1);
    buf[sizeof buf - 1] = '\0';

    for (char *tok = strtok(buf, DELIMS); tok != NULL; tok = strtok(NULL, DELIMS)) {
        /* відкинути неалфавітні символи на початку (напр. «, —, ') */
        while (*tok != '\0' && !starts_with_alnum(tok)) {
            uint32_t cp;
            tok += utf8_decode(tok, &cp);
        }
        /* відкинути неалфавітні символи в кінці: шукаємо кінець останньої літери/цифри */
        char *end = tok, *p = tok;
        while (*p != '\0') {
            uint32_t cp;
            int len = utf8_decode(p, &cp);
            if (cp_is_letter(cp) || (cp < 0x80 && isdigit((int)cp))) end = p + len;
            p += len;
        }
        *end = '\0';
        if (*tok == '\0') continue;                 /* токен без літер (напр. "—") */
        if (!strlist_add(words, tok)) return (size_t)-1;
        added++;
    }
    return added;
}

TextStats text_stats(const StrList *lines, size_t word_count)
{
    TextStats st = {0, word_count, 0};
    int in_sentence = 0;   /* чи є незавершене речення */
    for (size_t i = 0; i < lines->count; i++) {
        const char *s = lines->items[i];
        st.chars += utf8_strlen(s);
        for (const char *p = s; *p != '\0'; p++) {
            if (*p == '.' || *p == '!' || *p == '?') {
                if (in_sentence) st.sentences++;    /* "...", "?!" - одне речення */
                in_sentence = 0;
            } else if (!isspace((unsigned char)*p)) {
                in_sentence = 1;
            }
        }
    }
    if (in_sentence) st.sentences++;                /* останнє речення без крапки */
    return st;
}

/** Пара "слово в нижньому регістрі - ключ анаграми". */
typedef struct {
    char *word;
    char *key;
} KeyedWord;

/** Порівняння для qsort: спочатку за ключем, потім за словом. */
static int cmp_keyed(const void *a, const void *b)
{
    const KeyedWord *x = (const KeyedWord *)a, *y = (const KeyedWord *)b;
    int c = strcmp(x->key, y->key);
    return c != 0 ? c : strcmp(x->word, y->word);
}

/** Звільняє масив пар (слово, ключ) з n заповнених елементів. */
static void free_keyed(KeyedWord *kw, size_t n)
{
    for (size_t i = 0; i < n; i++) { free(kw[i].word); free(kw[i].key); }
    free(kw);
}

int find_anagram_groups(const StrList *words, StrList *groups)
{
    size_t n = words->count;
    if (n == 0) return 1;
    KeyedWord *kw = (KeyedWord *)calloc(n, sizeof(KeyedWord));
    if (kw == NULL) return 0;

    size_t m = 0;
    for (size_t i = 0; i < n; i++) {
        size_t len = strlen(words->items[i]);
        kw[m].word = (char *)malloc(len * 2 + 1);   /* запас: нижній регістр може бути довшим */
        kw[m].key  = (char *)malloc(len * 2 + 1);
        if (kw[m].word == NULL || kw[m].key == NULL) { free_keyed(kw, m + 1); return 0; }
        word_to_lower(words->items[i], kw[m].word);
        if (make_anagram_key(words->items[i], kw[m].key) < 2) {   /* однолітерні слова пропускаємо */
            free(kw[m].word); free(kw[m].key);
            kw[m].word = kw[m].key = NULL;
            continue;
        }
        m++;
    }
    qsort(kw, m, sizeof(KeyedWord), cmp_keyed);

    /* Проходимо відсортований масив: однакові ключі стоять поруч */
    char line[MAX_LINE * 8];
    size_t i = 0;
    while (i < m) {
        size_t j = i + 1, distinct = 1;
        size_t pos = (size_t)snprintf(line, sizeof line, "%s", kw[i].word);
        while (j < m && strcmp(kw[j].key, kw[i].key) == 0) {
            if (strcmp(kw[j].word, kw[j - 1].word) != 0) {          /* пропуск повторів слова */
                if (pos < sizeof line)
                    pos += (size_t)snprintf(line + pos, sizeof line - pos, " %s", kw[j].word);
                distinct++;
            }
            j++;
        }
        if (distinct >= 2 && !strlist_add(groups, line)) { free_keyed(kw, m); return 0; }
        i = j;
    }
    free_keyed(kw, m);
    return 1;
}

 */
static size_t read_lines(FILE *in, StrList *lines, int interactive)
{
    char buf[MAX_LINE * 4 + 2];     /* до 4 байтів на символ UTF-8 */
    size_t n = 0;
    if (interactive)
        printf("Введіть текст (кілька рядків, до %d символів кожен).\n"
               "Порожній рядок - завершення введення:\n", MAX_LINE);
    while (fgets(buf, sizeof buf, in) != NULL) {
        size_t len = strlen(buf);
        int complete = (len > 0 && buf[len - 1] == '\n');
        buf[strcspn(buf, "\r\n")] = '\0';
        if (!complete && !feof(in)) {                 /* рядок не вмістився - відкинути решту */
            int ch;
            while ((ch = fgetc(in)) != '\n' && ch != EOF) { }
            printf("  Попередження: рядок %zu задовгий і був обрізаний.\n", n + 1);
        }
        if (utf8_strlen(buf) > MAX_LINE) {
            printf("  Попередження: рядок %zu довший за %d символів - обрізано.\n", n + 1, MAX_LINE);
            /* обрізаємо по межі символу */

            *p = '\0';
        }
        if (interactive && buf[0] == '\0') break;
        if (!strlist_add(lines, buf)) return (size_t)-1;
        n++;
    }
    return n;
}

int is_leap(int year)
{
    return (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
}

int date_valid(Date d)
{
    static const int dm[12] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    if (d.year < 1990 || d.year > 2100 || d.month < 1 || d.month > 12) return 0;
    int maxd = dm[d.month - 1] + (d.month == 2 && is_leap(d.year));
    return d.day >= 1 && d.day <= maxd;
}

int date_cmp(Date a, Date b)
{
    if (a.year != b.year) return a.year - b.year;
    if (a.month != b.month) return a.month - b.month;
    return a.day - b.day;
}

{
    char tail;
    if (sscanf(s, "%d.%d.%d%c", &d->day, &d->month, &d->year, &tail) != 3) return 0;
    return date_valid(*d);
}

int list_append(BusList *l, const Bus *b)
{
    BusNode *node = (BusNode *)malloc(sizeof(BusNode));
    if (node == NULL) return 0;
    node->data = *b;
    node->next = NULL;
    if (l->head == NULL) {
        l->head = node;
    } else {
        BusNode *p = l->head;
        while (p->next != NULL) p = p->next;
        p->next = node;
    }
    l->size++;
    return 1;
}

{
    for (BusNode *p = l->head; p != NULL; p = p->next)
        if (p->data.id == id) return p;

{
    BusNode **pp = &l->head;              /* покажчик на поле, що вказує на поточний вузол */
    while (*pp != NULL) {
        if ((*pp)->data.id == id) {
            BusNode *victim = *pp;
            *pp = victim->next;
            free(victim);
            l->size--;
            return 1;
        }
        pp = &(*pp)->next;
    }
    return 0;
}

/** Порівняння двох записів за полем. */
static int bus_cmp(const Bus *a, const Bus *b, SortField f)
{
    switch (f) {
        case SORT_ID:            return (a->id > b->id) - (a->id < b->id);
        case SORT_REG:           return strcmp(a->reg_number, b->reg_number);
        case SORT_MODEL:         return strcmp(a->model, b->model);
        case SORT_YEAR:          return (a->year > b->year) - (a->year < b->year);
        case SORT_MILEAGE:       return (a->mileage > b->mileage) - (a->mileage < b->mileage);
        case SORT_SINCE_SERVICE: {
            long x = km_since_service(a), y = km_since_service(b);
            return (x > y) - (x < y);
        }
        case SORT_DATE:          return date_cmp(a->last_service, b->last_service);
        default:                 return 0;
    }
}

/** Злиття двох відсортованих ланцюжків вузлів (стабільне). */
static BusNode *merge_nodes(BusNode *a, BusNode *b, SortField f, int asc)
{
    BusNode dummy;
    BusNode *tail = &dummy;
    dummy.next = NULL;
    while (a != NULL && b != NULL) {
        int c = bus_cmp(&a->data, &b->data, f);
        if (!asc) c = -c;
        if (c <= 0) { tail->next = a; a = a->next; }
        else        { tail->next = b; b = b->next; }
        tail = tail->next;
    }
    tail->next = (a != NULL) ? a : b;
    return dummy.next;
}

/** Рекурсивне сортування злиттям ланцюжка вузлів, O(n log n). */
static BusNode *merge_sort_nodes(BusNode *head, SortField f, int asc)
{
    if (head == NULL || head->next == NULL) return head;
    BusNode *slow = head, *fast = head->next;    /* пошук середини: "черепаха і заєць" */
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }
    BusNode *second = slow->next;
    slow->next = NULL;
    return merge_nodes(merge_sort_nodes(head, f, asc), merge_sort_nodes(second, f, asc), f, asc);
}

void list_sort(BusList *l, SortField field, int ascending)
{
    l->head = merge_sort_nodes(l->head, field, ascending);
}

/**

#include <stdio.h>

#include <string.h>

const char *storage_msg(StorageStatus s)
{
    switch (s) {
        case ST_OK:        return "успішно";
        case ST_OPEN_ERR:  return "не вдалося відкрити файл";
        case ST_READ_ERR:  return "помилка читання або пошкоджений файл";
        case ST_WRITE_ERR: return "помилка запису у файл";
        case ST_NOT_FOUND: return "запис не знайдено";
        case ST_NO_MEMORY: return "нестача пам'яті";
        default:           return "невідома помилка";
    }
}

StorageStatus storage_load(const char *path, BusList *l)
{
    FILE *f = fopen(path, "rb");
    if (f == NULL) return ST_OK;                    /* файла ще немає - порожня база */
    Bus b;
    StorageStatus st = ST_OK;
    for (;;) {
        size_t got = fread(&b, sizeof(Bus), 1, f);
        if (got != 1) {
            if (ferror(f)) st = ST_READ_ERR;
            else if (!feof(f)) st = ST_READ_ERR;
            break;                                  /* кінець файла */
        }
        if (!bus_valid(&b, NULL)) { st = ST_READ_ERR; break; }   /* пошкоджений запис */
        if (!list_append(l, &b)) { st = ST_NO_MEMORY; break; }
    }
    /* неповний останній запис: розмір файла не кратний sizeof(Bus) */
    if (st == ST_OK && fseek(f, 0, SEEK_END) == 0 && ftell(f) % (long)sizeof(Bus) != 0) st = ST_READ_ERR;
    fclose(f);
    return st;
}

StorageStatus storage_save(const char *path, const BusList *l)
{
    FILE *f = fopen(path, "wb");
    if (f == NULL) return ST_OPEN_ERR;
    for (const BusNode *p = l->head; p != NULL; p = p->next)
        if (fwrite(&p->data, sizeof(Bus), 1, f) != 1) { fclose(f); return ST_WRITE_ERR; }
    if (fclose(f) != 0) return ST_WRITE_ERR;
    return ST_OK;
}

StorageStatus storage_append(const char *path, const Bus *b)
{
    FILE *f = fopen(path, "ab");
    if (f == NULL) return ST_OPEN_ERR;
    size_t w = fwrite(b, sizeof(Bus), 1, f);
    if (fclose(f) != 0 || w != 1) return ST_WRITE_ERR;
    return ST_OK;
}

StorageStatus storage_update(const char *path, const Bus *b, long *pos_out)
{
    FILE *f = fopen(path, "r+b");
    if (f == NULL) return ST_OPEN_ERR;
    Bus cur;
    StorageStatus st = ST_NOT_FOUND;
    for (;;) {
        long pos = ftell(f);                        /* позиція початку поточного запису */
        if (fread(&cur, sizeof(Bus), 1, f) != 1) {
            if (ferror(f)) st = ST_READ_ERR;
            break;
        }
        if (cur.id == b->id) {
            if (fseek(f, pos, SEEK_SET) != 0) { st = ST_READ_ERR; break; }
            if (fwrite(b, sizeof(Bus), 1, f) != 1) { st = ST_WRITE_ERR; break; }
            if (pos_out != NULL) *pos_out = pos;
            st = ST_OK;
            break;
        }
    }
    if (fclose(f) != 0 && st == ST_OK) st = ST_WRITE_ERR;
    return st;
}

/** Видаляє пробіли на початку і в кінці рядка (на місці). */
static char *trim(char *s)
{
    while (*s == ' ' || *s == '\t') s++;
    size_t n = strlen(s);
    while (n > 0 && (s[n - 1] == ' ' || s[n - 1] == '\t' || s[n - 1] == '\r' || s[n - 1] == '\n')) s[--n] = '\0';
    return s;
}

/**
 * Розбирає один рядок CSV у структуру (strtok за комами).
 * @return 1 - успішно, 0 - некоректний рядок
 */
static int parse_csv_line(char *line, Bus *b, const char **err)
{
    char *field[9];
    int n = 0;
    for (char *tok = strtok(line, ","); tok != NULL && n < 9; tok = strtok(NULL, ","))
        field[n++] = trim(tok);
    if (n != 9 || strtok(NULL, ",") != NULL) { *err = "очікується 9 полів"; return 0; }

    memset(b, 0, sizeof *b);
    char tail;
    int status;
    if (sscanf(field[0], "%d%c", &b->id, &tail) != 1) { *err = "id не є числом"; return 0; }
    if (strlen(field[1]) >= REG_LEN) { *err = "держномер задовгий"; return 0; }
    strcpy(b->reg_number, field[1]);
    if (strlen(field[2]) >= MODEL_LEN) { *err = "назва моделі задовга"; return 0; }
    strcpy(b->model, field[2]);
    if (sscanf(field[3], "%d%c", &b->year, &tail) != 1) { *err = "рік не є числом"; return 0; }
    if (sscanf(field[4], "%d%c", &b->seats, &tail) != 1) { *err = "місця не є числом"; return 0; }
    if (sscanf(field[5], "%ld%c", &b->mileage, &tail) != 1) { *err = "пробіг не є числом"; return 0; }
    if (sscanf(field[6], "%ld%c", &b->last_service_km, &tail) != 1) { *err = "пробіг ТО не є числом"; return 0; }
    if (!date_parse(field[7], &b->last_service)) { *err = "некоректна дата ТО"; return 0; }
    if (sscanf(field[8], "%d%c", &status, &tail) != 1) { *err = "стан не є числом"; return 0; }
    b->status = (BusStatus)status;
    return bus_valid(b, err);
}

StorageStatus storage_import_csv(const char *path, BusList *l, int *imported, int *skipped)
{
    *imported = *skipped = 0;
    FILE *f = fopen(path, "r");
    if (f == NULL) return ST_OPEN_ERR;
    char line[512];
    int lineno = 0;
    while (fgets(line, sizeof line, f) != NULL) {
        lineno++;
        if (lineno == 1) continue;                  /* заголовок */
        if (trim(line)[0] == '\0') continue;        /* порожній рядок */
        Bus b;
        const char *err = NULL;
        if (!parse_csv_line(line, &b, &err)) {
            printf("  Рядок %d пропущено: %s\n", lineno, err ? err : "помилка формату");
            (*skipped)++;
            continue;
        }
        if (list_find_id(l, b.id) != NULL) {
            printf("  Рядок %d пропущено: id %d уже існує\n", lineno, b.id);
            (*skipped)++;
            continue;
        }
        if (!list_append(l, &b)) { fclose(f); return ST_NO_MEMORY; }
        (*imported)++;
    }
    StorageStatus st = ferror(f) ? ST_READ_ERR : ST_OK;
    fclose(f);
    return st;
}

StorageStatus report_service_due(const char *path, const BusList *l, long interval, int *found)
{
    *found = 0;
    /* відбір у тимчасовий список і сортування за перевищенням (спадання) */
    BusList due;
    list_init(&due);
    for (BusNode *p = l->head; p != NULL; p = p->next)
        if (km_since_service(&p->data) >= interval)
            if (!list_append(&due, &p->data)) { list_free(&due); return ST_NO_MEMORY; }
    list_sort(&due, SORT_SINCE_SERVICE, 0);
    *found = (int)due.size;

    FILE *f = fopen(path, "w");
    if (f == NULL) { list_free(&due); return ST_OPEN_ERR; }
    time_t now = time(NULL);
    char stamp[32];
    strftime(stamp, sizeof stamp, "%d.%m.%Y %H:%M", localtime(&now));

    FILE *outs[2] = {stdout, f};
    for (int k = 0; k < 2; k++) {
        FILE *out = outs[k];
        fprintf(out, "ЗВІТ: автобуси, яким за пробігом потрібне технічне обслуговування\n");
        fprintf(out, "Інтервал ТО: %ld км. Сформовано: %s\n", interval, stamp);
        if (due.size == 0) {
            fprintf(out, "Таких автобусів немає.\n");
            continue;
        }
        bus_print_header(out);
        for (BusNode *p = due.head; p != NULL; p = p->next) bus_print_row(out, &p->data);
        bus_print_footer(out);
        fprintf(out, "Усього: %zu з %zu автобусів. Перевищення інтервалу (км):", due.size, l->size);
        for (BusNode *p = due.head; p != NULL; p = p->next)
            fprintf(out, " %s=%ld", p->data.reg_number, km_since_service(&p->data) - interval);
        fprintf(out, "\n");
    }
    list_free(&due);
    if (fclose(f) != 0) return ST_WRITE_ERR;
    return ST_OK;
}

/**
 * Читає рядок з клавіатури (fgets) без символу '\n'.
 * @return 1 - успішно, 0 - кінець вхідного потоку
 */
static int read_line(const char *prompt, char *buf, size_t size)
{
    printf("%s", prompt);
    if (fgets(buf, (int)size, stdin) == NULL) return 0;
    size_t n = strcspn(buf, "\r\n");
    if (buf[n] == '\0' && n == size - 1) flush_line();   /* рядок задовгий - відкинути решту */
    buf[n] = '\0';
    return 1;
}

/**
 * Читає ціле в межах [lo; hi] з повторним запитом.
 * Порожній ввід при наявності def_value повертає значення за замовчуванням.
 * @return 1 - успішно, 0 - кінець вводу
 */
static int read_long(const char *prompt, long lo, long hi, long *value, const long *def_value)
{
    char buf[64], tail;
    for (;;) {
        if (!read_line(prompt, buf, sizeof buf)) return 0;
        if (buf[0] == '\0' && def_value != NULL) { *value = *def_value; return 1; }
        if (sscanf(buf, "%ld %c", value, &tail) == 1 && *value >= lo && *value <= hi) return 1;
        printf("  Помилка: потрібне ціле число від %ld до %ld.\n", lo, hi);
    }
}

/** Читає рядок довжиною 1..maxlen-1 символів; def - значення для порожнього вводу. */
static int read_text(const char *prompt, char *out, size_t maxlen, const char *def)
{
    char buf[128];
    for (;;) {
        if (!read_line(prompt, buf, sizeof buf)) return 0;
        if (buf[0] == '\0' && def != NULL) { strcpy(out, def); return 1; }
        if (buf[0] != '\0' && strlen(buf) < maxlen && strchr(buf, ',') == NULL) { strcpy(out, buf); return 1; }
        printf("  Помилка: рядок має бути непорожнім, без коми, до %zu байт.\n", maxlen - 1);
    }
}

/** Читає дату ДД.ММ.РРРР; def - значення для порожнього вводу (може бути NULL). */
static int read_date(const char *prompt, Date *d, const Date *def)
{
    char buf[64];
    for (;;) {
        if (!read_line(prompt, buf, sizeof buf)) return 0;
        if (buf[0] == '\0' && def != NULL) { *d = *def; return 1; }
        if (date_parse(buf, d)) return 1;
        printf("  Помилка: потрібна існуюча дата у форматі ДД.ММ.РРРР (1990..2100).\n");
    }
}

/**
 * Введення (або редагування, якщо old != NULL) полів запису.
 * Під час редагування порожній ввід залишає старе значення.
 * @return 1 - запис введено коректно, 0 - скасовано / кінець вводу
 */
static int input_bus(Bus *b, const Bus *old)
{
    char prompt[128];
    long v, def;
    if (old != NULL) printf("(Enter - залишити поточне значення)\n");

    snprintf(prompt, sizeof prompt, "Держномер%s%s%s: ", old ? " [" : "", old ? old->reg_number : "", old ? "]" : "");
    for (;;) {   /* BUG-05-01: довжину держномера перевіряємо одразу, а не після введення всіх полів */
        if (!read_text(prompt, b->reg_number, REG_LEN, old ? old->reg_number : NULL)) return 0;
        if (strlen(b->reg_number) >= 4) break;
        printf("  Помилка: держномер має містити від 4 до %d символів.\n", REG_LEN - 1);
    }
    snprintf(prompt, sizeof prompt, "Модель%s%s%s: ", old ? " [" : "", old ? old->model : "", old ? "]" : "");
    if (!read_text(prompt, b->model, MODEL_LEN, old ? old->model : NULL)) return 0;

    def = old ? old->year : 0;
    snprintf(prompt, sizeof prompt, "Рік випуску (1990..2100)%s: ", old ? " [поточне]" : "");
    if (!read_long(prompt, 1990, 2100, &v, old ? &def : NULL)) return 0;
    b->year = (int)v;

    def = old ? old->seats : 0;
    snprintf(prompt, sizeof prompt, "Кількість місць (1..300)%s: ", old ? " [поточне]" : "");
    if (!read_long(prompt, 1, 300, &v, old ? &def : NULL)) return 0;
    b->seats = (int)v;

    def = old ? old->mileage : 0;
    snprintf(prompt, sizeof prompt, "Поточний пробіг, км%s: ", old ? " [поточне]" : "");
    if (!read_long(prompt, 0, 5000000L, &v, old ? &def : NULL)) return 0;
    b->mileage = v;

    for (;;) {
        def = old ? old->last_service_km : 0;
        snprintf(prompt, sizeof prompt, "Пробіг на момент останнього ТО, км%s: ", old ? " [поточне]" : "");
        if (!read_long(prompt, 0, 5000000L, &v, old ? &def : NULL)) return 0;
        if (v <= b->mileage) break;
        printf("  Помилка: пробіг на ТО не може перевищувати поточний пробіг (%ld).\n", b->mileage);
    }
    b->last_service_km = v;

    for (;;) {
        if (!read_date("Дата останнього ТО (ДД.ММ.РРРР): ", &b->last_service, old ? &old->last_service : NULL)) return 0;
        if (b->last_service.year >= b->year) break;
        printf("  Помилка: дата ТО не може бути раніше року випуску.\n");
    }

    def = old ? (long)old->status : 0;
    if (!read_long("Стан (0 - на лінії, 1 - у ремонті, 2 - у резерві): ", 0, 2, &v, old ? &def : NULL)) return 0;
    b->status = (BusStatus)v;

    const char *err = NULL;
    if (!bus_valid(b, &err)) { printf("  Запис некоректний: %s\n", err); return 0; }
    return 1;
}

/** Пункт меню «Пошук за держномером» (точний збіг без урахування регістру). */
static void search_by_reg(const BusList *l)
{
    char key[REG_LEN + 8];
    if (!read_text("Держномер для пошуку: ", key, sizeof key, NULL)) return;
    int found = 0;
    for (BusNode *p = l->head; p != NULL; p = p->next) {
        const char *a = p->data.reg_number, *b = key;
        while (*a && *b && toupper((unsigned char)*a) == toupper((unsigned char)*b)) { a++; b++; }
        if (*a == '\0' && *b == '\0') {
            if (!found) bus_print_header(stdout);
            bus_print_row(stdout, &p->data);
            found++;
        }
    }
    if (found) bus_print_footer(stdout); else printf("Автобус з номером %s не знайдено.\n", key);
}

/** Пункт меню «Пошук за моделлю» (входження підрядка, strstr). */
static void search_by_model(const BusList *l)
{
    char key[MODEL_LEN];
    if (!read_text("Модель або її частина: ", key, sizeof key, NULL)) return;

            if (!found) bus_print_header(stdout);
            bus_print_row(stdout, &p->data);
            found++;
        }
    if (found) { bus_print_footer(stdout); printf("Знайдено: %d\n", found); }
    else printf("Автобусів моделі «%s» не знайдено.\n", key);
}

Файл common/memtrack.c
/**
 * @file memtrack.c
 * @brief Реалізація детектора витоків пам'яті (див. memtrack.h).
 *
 * Таблиця блоків - статичний масив (це службовий модуль налагодження,
 * тому тут допускається внутрішній стан на рівні файла).
 */
#define MEMTRACK_IMPL
#include <stdio.h>
#include "memtrack.h"

#define MT_MAX 65536

typedef struct {
    void       *ptr;
    size_t      size;
    const char *file;
    int         line;
} MtBlock;

static MtBlock blocks[MT_MAX];
static size_t  n_blocks, n_alloc, n_free, n_bad_free, peak_bytes, cur_bytes, total_bytes;
static int     registered;

static void mt_report(void)
{
    fprintf(stderr, "\n==MEMTRACK== ЗВІТ ПРО ВИКОРИСТАННЯ ДИНАМІЧНОЇ ПАМ'ЯТІ\n");
    fprintf(stderr, "==MEMTRACK== виділень: %zu, звільнень: %zu, усього виділено: %zu байт, пік: %zu байт\n",
            n_alloc, n_free, total_bytes, peak_bytes);
    size_t leaked = 0;
    for (size_t i = 0; i < n_blocks; i++)
        if (blocks[i].ptr != NULL) {
            fprintf(stderr, "==MEMTRACK== ВИТІК: %zu байт, виділено у %s:%d\n",
                    blocks[i].size, blocks[i].file, blocks[i].line);
            leaked += blocks[i].size;
        }
    if (n_bad_free) fprintf(stderr, "==MEMTRACK== некоректних free(): %zu\n", n_bad_free);
    if (leaked == 0 && n_bad_free == 0)
        fprintf(stderr, "==MEMTRACK== Усі блоки звільнено. Витоків пам'яті не виявлено.\n");
    else
        fprintf(stderr, "==MEMTRACK== ПІДСУМОК: втрачено %zu байт\n", leaked);
}

static void mt_add(void *p, size_t size, const char *file, int line)
{
    if (!registered) { atexit(mt_report); registered = 1; }
    if (p == NULL) return;
    n_alloc++;
    total_bytes += size;
    cur_bytes += size;
    if (cur_bytes > peak_bytes) peak_bytes = cur_bytes;
    for (size_t i = 0; i < n_blocks; i++)          /* повторно використати вільну комірку */
        if (blocks[i].ptr == NULL) { blocks[i] = (MtBlock){p, size, file, line}; return; }
    if (n_blocks < MT_MAX) blocks[n_blocks++] = (MtBlock){p, size, file, line};
}

/** Вилучає блок з таблиці; повертає 1, якщо покажчик був відомий. */
static int mt_remove(void *p)
{
    for (size_t i = 0; i < n_blocks; i++)
        if (blocks[i].ptr == p) {
            cur_bytes -= blocks[i].size;
            blocks[i].ptr = NULL;
            return 1;
        }
    return 0;
}

void *mt_malloc(size_t size, const char *file, int line)
{
    void *p = malloc(size);
    mt_add(p, size, file, line);
    return p;
}

void *mt_calloc(size_t n, size_t size, const char *file, int line)
{
    void *p = calloc(n, size);
    mt_add(p, n * size, file, line);
    return p;
}

void *mt_realloc(void *old, size_t size, const char *file, int line)
{
    /* Індекс старого блоку шукаємо ДО realloc: після успішного realloc
       старий покажчик недійсний, і порівнювати його вже не можна. */
    size_t idx = MT_MAX;
    if (old != NULL)
        for (size_t i = 0; i < n_blocks; i++)
            if (blocks[i].ptr == old) { idx = i; break; }
    void *p = realloc(old, size);
    if (p != NULL) {
        if (idx != MT_MAX) {
            cur_bytes -= blocks[idx].size;
            blocks[idx].ptr = NULL;
            n_free++;
        }
        mt_add(p, size, file, line);
    }
    return p;
}

void mt_free(void *p, const char *file, int line)
{
    if (p == NULL) return;                          /* free(NULL) допустимий */
    if (!mt_remove(p)) {
        n_bad_free++;
        fprintf(stderr, "==MEMTRACK== ПОМИЛКА: free() невідомого або вже звільненого покажчика у %s:%d\n",
                file, line);
        return;                                     /* не передаємо в free(), щоб уникнути збою */
    }
    n_free++;
    free(p);
}

static void test_quick_vs_bubble_counts(void)
{
    enum { N = 1000 };
    static int a[N], b[N];
    unsigned int seed = 12345u;
    for (int i = 0; i < N; i++) {                /* детермінований псевдовипадковий масив */
        seed = seed * 1103515245u + 12345u;
        a[i] = b[i] = (int)((seed >> 16) % 101) - 50;
    }
    SortStats sb = {0, 0}, sq = {0, 0};
    bubble_sort(a, N, &sb);
    quick_sort(b, N, &sq);
    CU_ASSERT_TRUE(is_sorted(a, N) && is_sorted(b, N));
    CU_ASSERT_TRUE(memcmp(a, b, sizeof a) == 0);
    CU_ASSERT_TRUE(sb.comparisons <= (unsigned long long)N * (N - 1) / 2);
    CU_ASSERT_TRUE(sq.comparisons * 10 < sb.comparisons);   /* O(n log n) << O(n^2) */
}

static void test_binary_search_all_positions(void)

    }
}

static void test_utf8_roundtrip(void)

}
