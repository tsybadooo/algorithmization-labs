1 Створення проєкту консольного додатка

Порядок створення проєкту в MS Visual Studio за методичними вказівками: меню File/New/Project → Visual C++/Win32 Console Application, назва lab01a, у вікні Application Settings — тип Console application. До папки Header Files через Add/New Item додається файл lab01a.h, який підключається до lab01a.cpp директивою #include у подвійних лапках (пошук у каталозі проєкту), а стандартні бібліотеки stdio.h і math.h — у кутових дужках (пошук у системних каталогах). Build/Build Solution компілює лише змінені файли, Build/Rebuild Solution — увесь проєкт; запуск — Debug/Start Without Debugging.

Структура проєкту в цій роботі така сама (заголовковий файл lab01a.h і файл реалізації lab01a.cpp), а збирання й налагодження виконано компілятором GCC 16.1 (MSYS2) і налагоджувачем gdb командою g++ -Wall -Wextra -g -o lab01a.exe lab01a.cpp — 0 помилок, 0 попереджень. Код не використовує нестандартних засобів, тому без змін компілюється і в MS Visual Studio.

Для перевірки механізму виявлення помилок у код внесено помилку int i = j; — використання змінної до її оголошення. Компілятор повідомляє файл, рядок і позицію помилки, а виконуваний файл не створюється:

2 Алгоритм розв’язання задачі

За теоремою Піфагора другий катет b = √(c² − a²), площа прямокутного трикутника S = a·b / 2. Алгоритм лінійний: введення (задання) даних, обчислення, виведення результату.

Рисунок 1 – Блок-схема алгоритму обчислення площі прямокутного трикутника

3 Текст програми

Файл lab01a.h
/* lab01a.h - Лабораторна робота №1, варіант 19 (за таблицею - №5)
   Обчислення площі прямокутного трикутника за катетом a і гіпотенузою c.
   Вхідні дані задано константами. */
#ifndef LAB01A_H
#define LAB01A_H

#define LEG_A        3.0   /* катет a, см      */
#define HYPOTENUSE_C 5.0   /* гіпотенуза c, см */

#endif
Файл lab01a.cpp
/* lab01a.cpp - Лабораторна робота №1
   Варіант 19 (5): обчислити площу прямокутного трикутника
   за довжинами його катета a і гіпотенузи c.
   Алгоритм (лінійний):
     1) b = sqrt(c*c - a*a)   - другий катет (теорема Піфагора);
     2) S = a * b / 2         - площа прямокутного трикутника;
     3) вивести a, c, b, S.                                        */
#include <stdio.h>
#include <math.h>
#include "../common_console.h"
#include "lab01a.h"

int main()
{
    console_utf8();
    const double a = LEG_A;          /* катет      */
    const double c = HYPOTENUSE_C;   /* гіпотенуза */
    double b, s;

    b = sqrt(c * c - a * a);         /* другий катет */
    s = a * b / 2.0;                 /* площа        */

    printf("Лабораторна робота №1. Варіант 19 (5)\n");
    printf("Катет a      = %.3f\n", a);
    printf("Гіпотенуза c = %.3f\n", c);
    printf("Катет b      = %.3f\n", b);
    printf("Площа S      = %.3f\n", s);
    return 0;
}

Допоміжний заголовковий файл common_console.h перемикає консоль Windows на кодування UTF-8, щоб коректно виводився український текст:

Файл common_console.h
/* common_console.h - налаштування консолі Windows на UTF-8,
   щоб коректно виводився український текст. */
#ifndef COMMON_CONSOLE_H
#define COMMON_CONSOLE_H
#ifdef _WIN32
#include <windows.h>
static void console_utf8(void) { SetConsoleOutputCP(CP_UTF8); SetConsoleCP(CP_UTF8); }
#else
static void console_utf8(void) { }
#endif
#endif

Відповіді на контрольні питання

1. Що таке об’ява? Наведіть приклади об’яв допустимих в мові С++. Об’ява (оголошення) вводить ім’я в програму і повідомляє компілятору його тип: int a;, const double PI = 3.14;, double f(int);, extern int g;, struct Point;.

2. Що таке тип і що він визначає? Тип визначає множину допустимих значень, розмір пам’яті, спосіб подання даних і набір операцій над ними.

3. Які вбудовані типи даних є в мові С++? Логічний bool; символьні char, wchar_t, char16_t, char32_t; цілі short, int, long, long long (signed/unsigned); дійсні float, double, long double; void.

4. Які вимоги і обмеження пред’являються до цілочисельних типів даних в мові С++? Стандарт гарантує лише мінімальні розміри і співвідношення: sizeof(char)=1 ≤ short ≤ int ≤ long ≤ long long; short і int — щонайменше 16 біт, long — 32, long long — 64. Переповнення знакових типів є невизначеною поведінкою, беззнакові обчислюються за модулем 2ⁿ.

5. Чим відрізняються цілочисельні типи даних від дійсних? Цілі зберігають точні значення без дробової частини, ділення цілих відкидає дробову частину; дійсні зберігаються у форматі з рухомою комою (мантиса і порядок), мають великий діапазон, але обмежену точність і похибки округлення.

6. Для чого призначений логічний тип даних? Тип bool зберігає значення true/false і використовується в умовах розгалужень, циклів та для результатів логічних і порівняльних операцій.

7. Визначення розміру типів даних в мові С++? Операцією sizeof, напр. sizeof(int) або sizeof x; результат має тип size_t і вимірюється в байтах; межі значень — у <climits>/<limits>.

8. Які основні операції можуть бути застосовані до об’єктів цілочисельних типів даних? Арифметичні (+ − * / %), інкремент/декремент, порівняння, логічні, порозрядні (& | ^ ~ << >>), присвоєння та складені присвоєння.

9. Що таке літеральні константи і які правила їх об’яви? Літерали — значення, записані безпосередньо в коді: 10, 0x1F, 017, 10u, 10L, 3.14, 2.5f, 1e-3, 'A', "текст". Тип визначається формою запису і суфіксом.

10. Чим відрізняються об’яви змінних і констант? Константа оголошується з const (або constexpr), обов’язково ініціалізується і не може змінюватися після ініціалізації; змінну можна змінювати.

11. Що таке масив? Іменована послідовність фіксованої кількості елементів одного типу, розміщених у пам’яті поспіль; доступ — за індексом від 0.

12. Перерахуйте особливості ініціалізації елементів масиву. Ініціалізація списком у фігурних дужках; якщо значень менше за розмір — решта нулі; розмір можна не вказувати, тоді він визначається кількістю ініціалізаторів; char-масив можна ініціалізувати рядком.

13. Як визначити кількість елементів в масиві? sizeof(a) / sizeof(a[0]) (лише для масиву в області його оголошення, не для покажчика-параметра).

14. Які особливості доступу до елементів масиву? Індекси від 0 до N−1, вихід за межі не перевіряється і є невизначеною поведінкою; a[i] еквівалентно *(a + i).

15. Для чого застосовується модифікатор static? Для локальної змінної — зберігає значення між викликами (статичний час життя); для глобальних імен і функцій — обмежує видимість поточним файлом.

16. Чим визначається час існування об’єктів в програмі? Класом пам’яті: автоматичні (до виходу з блоку), статичні (весь час роботи програми), динамічні (від new/malloc до delete/free).

17. Для чого застосовується оператор кома? Обчислює вирази зліва направо і повертає значення останнього; типово використовується в заголовку for: for (i = 0, j = n; i < j; i++, j--).

18. Що таке простір імен і для чого він застосовується? namespace — іменована область видимості, що запобігає конфліктам імен; доступ через ::, напр. std::cout, або using namespace std.

19. Які способи приведення типів є в мові С++? Неявне (автоматичне), C-подібне (int)x, функціональне int(x), а також static_cast, const_cast, reinterpret_cast, dynamic_cast.

20. Що таке приведення типів, для чого воно потрібне? Перетворення значення одного типу в інший — для узгодження типів операндів, уникнення цілочисельного ділення (напр. (double)a/b), роботи з покажчиками тощо.
